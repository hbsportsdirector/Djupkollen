# Djupkollen

Realtidskoll av knäböjsdjup för handbollsgymnasiet. Öppna sidan på telefonen, ställ den från sidan i knähöjd, och hela skärmen blir grön, gul eller röd efter varje knäböj.

Godkänt = lårbenet parallellt med golvet (höftleden i knähöjd eller lägre). Allt körs lokalt i webbläsaren med MediaPipe Pose; ingen video lämnar telefonen.

Sidan ligger på GitHub Pages: https://hbsportsdirector.github.io/djupkollen/
